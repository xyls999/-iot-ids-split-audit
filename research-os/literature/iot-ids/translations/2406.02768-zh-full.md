## 摘要（Abstract）

入侵检测系统（Intrusion Detection Systems，IDS）在检测和防止传统计算系统中的网络攻击方面发挥了重要作用。将同样的技术应用于保护物联网（Internet of Things，IoT）网络免受网络威胁，并不令人意外。物联网设备可用的计算资源有限，这使得部署基于常规计算的 IDS 变得困难。为物联网环境设计的 IDS 还必须展现出较高的分类性能、使用低复杂度模型，并且尺寸较小。尽管基于物联网的入侵检测已经取得了显著进展，但要开发出同时实现高分类性能并保持低复杂度的模型，仍然具有挑战性。在本研究中，我们提出一种混合 CNN 架构，由轻量级卷积神经网络（Convolutional Neural Network，CNN）和双向长短期记忆网络（bidirectional Long Short-Term Memory，BiLSTM）组成，用于提升 IDS 在 UNSW-NB15 数据集上的性能。所提出的模型专门设计为在资源受限的物联网设备上运行，并满足其计算能力要求。尽管设计一个既适合物联网设备要求又能实现更高准确率的模型很复杂，但我们提出的模型仍优于文献中的现有研究：二分类准确率达到 97.28%，多分类准确率达到 96.91%。

**索引词（Index Terms）：** 入侵检测系统（Intrusion Detection Systems），深度学习（Deep Learning），卷积神经网络（Convolutional Neural Networks），长短期记忆（Long-Short-Term-Memory），UNSW-NB15。

## I. 引言（INTRODUCTION）

随着普适物联网网络不断扩展并实现互联，智慧城市的基础设施越来越容易受到网络攻击[1]。这些攻击可能通过中断关键服务和危及敏感数据来威胁公共安全。在这类互联网络中，入侵检测系统（IDS）在实时监测并识别恶意活动、使其在造成重大损害之前得到处理方面发挥着关键作用[2]。尽管现有 IDS 解决方案已经显示出有希望的结果，但它们在智慧城市环境中往往面临挑战。传统的基于规则的系统难以适应不断演变的攻击模式，而复杂的深度学习模型对于资源受限的智慧城市设备而言，计算成本高且需要大量资源[3]。这些物联网设备包括温度传感器以及用于监测灯泡或恒温器的智能设备，其特点是体积小、功能有限。这些设备收集的数据通过互联网传输以便存储和分析，因此必须采取安全措施来保护个人、私密或敏感信息[4]。

物联网通过引入自动化服务改善了人们的生活方式。由于这种不受约束的增长，隐私和安全问题变得越来越重要。由于物联网生态系统具有固有的动态性和多样性，解决这些问题是一项艰巨任务。试想保护智慧城市或智能家居这样的动态环境：它们的特点是网络可见性受限，并且设备在首次使用后缺少专业支持。这使传统网络安全方法难以应对该环境的动态性。用户隐私和环境整体安全所面临的风险还因以下事实而进一步增加：许多互联物联网设备设计不完善，也没有定期获得安全更新。因此，要充分实现物联网智能环境的潜力，需要采取既重视安全与隐私、又能够适应这一不断变化环境的创新解决方案[5]。

以往有关智慧城市 IDS 的研究主要采用决策树和支持向量机（Support Vector Machines，SVM）等传统机器学习（Machine Learning，ML）技术来提升 IDS 性能。虽然这些方法能够提供可观的准确率，但需要大量人工特征工程，并且通常会产生较高的误报率。相比之下，深度学习方法，尤其是卷积神经网络（CNN），由于能够从网络流量数据中自动提取特征，已经成为很有前景的替代方案。然而，它们较高的计算需求使其不适用于资源有限的智慧城市设备。在本研究中，我们提出以下几项关键贡献：

1. 我们提出一种新颖的混合方法，将轻量级 CNN 与双向长短期记忆（LSTM）网络相结合，以在物联网网络中实现高效且准确的入侵检测。

2. 我们开发了一种针对物联网设备优化的定制 CNN 架构，具有更少的层和参数，从而促进高效的数据处理。该架构能够高效地从网络流量中提取关键特征，随后由双向 LSTM 处理，以准确分类正常活动和恶意活动。

3. 我们的混合模型结合了 CNN 和 LSTM 的优势，解决了两种方法各自固有的局限性。

4. 为应对数据集不平衡这一挑战，我们在多分类模型中实现了加权损失函数。权重根据 UNSW-NB15 数据集中每种攻击类型的相对频率分配，从而提升模型的公平性和准确率。

本文其余部分的结构如下：第 2 节回顾与本研究相关的文献。第 3 节详细描述所提出的混合入侵检测方法，包括轻量级 CNN-BiLSTM 架构，并概述分析中使用的数据集和评估指标。第 4 节给出实验结果并讨论我们的发现。最后，第 5 节总结本文的贡献并说明未来研究方向。

## II. 相关工作（RELATED WORK）

文献[6]的作者针对物联网网络中的异常检测提出了一种 1D CNN-LSTM 模型。该模型利用 CNN 进行空间特征提取，并利用 LSTM 进行时间分析，在 Bot-IoT 数据集上实现了 99.20% 的准确率和 0.80% 的误报率。它支持二分类和多分类检测，超过了其他方法，并展示出实际应用的潜力。我们之前的论文[7]研究了一种利用条件生成对抗网络（conditional Generative Adversarial Networks，cGANs）改进物联网网络异常检测的新方法。我们通过生成逼真的对抗性恶意软件样本，解决了数据不平衡和特定攻击样本缺失的问题。这一训练过程增强了基于 CNNLSTM 的 IDS，使其对盗窃攻击的检测准确率提升了 40%。

许多研究者探索了利用 UNSW-NB15 数据集提升 IDS 性能的方法。该数据集因其真实且多样的网络流量数据而广受欢迎，其中包含正常活动和攻击活动。论文[8]使用前馈神经网络（Feed-Forward Neural Network）和 UNSW-NB15 数据集，研究深度学习在网络 IDS 中的应用。文章认为，由于现代网络威胁的复杂性，传统机器学习无法准确检测入侵。实验结果表明，作者通过找到最优的激活函数和特征，相比现有机器学习模型实现了更高的准确率和更低的误报率。论文[9]提出了用于网络入侵检测的 IGRF-RFE 混合特征选择方法，将过滤式和包裹式技术相结合。IGRF-RFE 成功识别并消除了无关特征，将特征数量从 42 个减少到 23 个，同时将 UNSW-NB15 数据集上的异常检测准确率从 82.25% 提升到 84.24%。这些结果表明，IGRF-RFE 可以成为构建更高效、更准确 IDS 的有价值工具。

文献[10]探索了使用带有新缩放方法的支持向量机（SVM）来检测现代 UNSW-NB15 数据集中的网络入侵。他们在二分类和多分类任务上将其方法与以往方法进行了比较。该论文强调，与较旧的方法和数据集相比，在更真实的 UNSW-NB15 数据集上，采用新缩放方法的 SVM 对入侵检测尤其有效。文献[11]的作者提出了一种用于保护物联网设备免受网络攻击的新网络入侵检测系统（Network Intrusion Detection System，NIDS）。该系统使用 LSTM 层，可以从过去的数据中学习，以识别已知和未知攻击。这相较于难以检测新攻击的旧方法有所改进。研究人员在两个大型网络流量数据集上测试了该系统，发现其比之前的方法准确率更高，同时减少了误报。

## III. 用于 UNSW-NB15 数据集的混合 CNN 模型（HYBRID CNN MODEL FOR THE UNSW-NB15 DATASET）

### A. UNSW-NB15 数据集描述（Description of the UNSW-NB15 dataset）

UNSW-NB15 数据集提供了现代网络流量的真实快照，既包含日常活动，也包含包括 DoS、后门和侦察在内的九种多样的当代攻击类型。它具有清晰的组织结构，包含十种不同的数据类型，并且正常流量与恶意流量的表示较为均衡，因此是开发和评估 IDS 的有价值资源。每种数据类型的详细信息见表 I。

本研究使用 UNSW-NB15 数据集，该数据集包含 257,673 个数据实例（175,341 个训练实例和 82,332 个测试实例），经过仔细划分且没有冗余，以确保 NIDS 评估可靠。两个集合包含相同的攻击类型，详见表 I。每个数据点有 44 个特征，分为六组：流（flow）、基本（basic）、内容（content）、时间（time）、额外生成特征（分为通用特征和连接特征）以及标记的攻击类别。特征 #1–#30 表示核心网络分组信息，而额外特征和连接特征（#31–#42）提供更深入的信息。标记特征（#43–#44）用于监督学习任务（见表 II）。这一综合数据集为探索现代网络（例如智慧城市中的物联网网络）中的入侵提供了稳健平台。

### B. 轻量级 CNN-BiLSTM（Lightweight CNN-BiLSTM）

传统 IDS 通常依赖基于规则的系统或浅层机器学习模型，而这些系统和模型可能难以应对网络攻击不断演变的性质以及资源受限物联网设备的资源约束。为应对这些挑战，我们提出一种新颖的混合模型，将轻量级卷积神经网络（CNN）的优势与双向长短期记忆（BiLSTM）层[12]相结合，以有效检测物联网网络中的入侵。

模型的第一阶段使用专门为边缘设备高效处理而设计的轻量级 CNN 架构。与标准 CNN 相比，该 CNN 使用更少的层和参数，在保持可接受准确率的同时降低计算复杂度和内存占用。卷积层从网络流量中提取空间特征，识别不同数据点之间的模式和关系。

![图 1：轻量级 CNN-BiLSTM 模型架构](figure-1-architecture)

**图 1：** 用于 UNSW-NB15 数据集分类、具有 7841 个可训练参数的轻量级 CNN-BiLSTM 模型架构

图 1 所示架构的数据流为：

```text
输入层（1, 56）
    ↓
一维卷积（Convolutional 1D）
filters=32, kernel size=3, padding="same", activation='relu'
    ↓
一维最大池化（MaxPooling1D），pool size=2, padding="same"
    ↓
双向 LSTM（Bidirectional LSTM），units=32, return sequences=True
    ↓
Dropout（0.2）
    ↓
全连接层（Dense）（25），activation='relu'
    ↓
输出层（1），activation='sigmoid'
```

提取的特征随后被送入 BiLSTM 层，该层擅长捕获序列数据中的时间依赖关系。这对于网络流量分析尤其有价值，因为网络攻击通常会随时间表现出特定模式。BiLSTM 分析特征序列，学习其内在动态，并识别偏离正常网络行为的异常。CNN 层和 BiLSTM 层的输出被组合起来，从而利用两种方法各自的优势。组合后的特征随后被送入最终决策层（例如 sigmoid 分类器），由其确定网络流量的类别（正常或恶意）。

BiLSTM 模型由一对 LSTM 单元组成。一个 LSTM 单元沿正向处理输入序列，另一个 LSTM 单元沿反向处理输入序列。在图 2 中可以看到，正向 LSTM 从输入序列的开头分析到结尾，而反向 LSTM 则沿相反方向运行。在每个时间步，两个 LSTM 的隐藏状态被组合或连接，以创建最终的隐藏状态序列。随后，该组合序列被转发到下一层。这一过程的数学表示由以下公式给出：

\[
h_t^{(f)} = LSTM^{(f)}(x_t, h_{t-1}^{(f)}, c_{t-1}^{(f)}) \tag{1}
\]

\[
h_t^{(b)} = LSTM^{(b)}(x_t, h_{t+1}^{(b)}, c_{t+1}^{(b)}) \tag{2}
\]

\[
h_t = [h_t^{(f)}; h_t^{(b)}] \tag{3}
\]

其中，$h_t^{(f)}$ 和 $h_t^{(b)}$ 分别表示时间步 $t$ 的正向和反向隐藏状态。$c_{t-1}^{(f)}$ 和 $c_{t-1}^{(b)}$ 分别表示时间步 $t$ 的正向和反向单元状态。$x_t$ 表示时间步 $t$ 的输入向量。$h_t$ 表示将正向和反向隐藏状态连接成的单一向量。

```text
输出层       hₜ₋₁          hₜ          hₜ₊₁

反向         LSTM         LSTM        LSTM
正向         LSTM         LSTM        LSTM

输入层       xₜ₋₁          xₜ          xₜ₊₁
```

### C. NIDS 性能测量：关键指标（Measuring NIDS Performance: Key Metrics）

为了评估 NIDS 的有效性，我们分析由混淆矩阵（confusion matrix）得到的关键指标。混淆矩阵映射系统对网络流量的分类准确性。本研究考虑以下参数：

1. **准确率（Accuracy）：** 衡量 NIDS 的总体正确性，反映所有预测中正确预测（包括攻击流量和正常流量）所占的比例。

\[
\text{Accuracy} = \frac{TP + TN}{TP + TN + FP + FN}
\]

2. **召回率（Recall，也称检测率 Detection Rate 或敏感度 Sensitivity）：** 衡量 NIDS 正确识别实际攻击的能力。它关注实际攻击中有多少被正确检测出来。

\[
\text{Recall} = \frac{TP}{TP + FN}
\]

3. **精确率（Precision）：** 衡量预测为攻击的样本中实际正确的比例。它关注预测的攻击中有多少是真正例。

\[
\text{Precision} = \frac{TP}{TP + FP}
\]

4. **F1 分数（F1-Score）：** 将精确率和召回率合并为单一指标，为 NIDS 性能提供均衡的视角。

\[
\text{F1-Score} = 2 * \frac{\text{Precision} * \text{Recall}}{\text{Precision} + \text{Recall}}
\]

虽然涵盖攻击和正常流量分类的总体准确率在评估 NIDS 性能方面发挥着关键作用，但其在不平衡数据集中的局限性很快就会显现。在这类场景中，我们优先考虑召回率，确保尽可能少地漏掉攻击，因为即使一个未检测到的威胁也可能带来重大后果。相反，高精确率能够最大限度地减少误报，对于避免资源耗尽并保持运行效率至关重要。最终，平衡这两个方面的 F1 分数为 NIDS 的有效性提供了更加细致的理解，在攻击检测和误报缓解之间取得平衡，从而实现稳健的网络安全。

## IV. 实验结果与分析（EXPERIMENTAL RESULTS AND ANALYSIS）

我们的实验使用 Python 和 TensorFlow，在一台标准 PC 上运行，研究了轻量级 CNN 相对于传统机器学习方法用于入侵检测的可行性。我们利用通用的 UNSW-NB15 数据集进行多分类，并在 TensorFlow 中构建定制 CNN 架构，以评估其相对于成熟方法的性能。该设置能够清晰比较这些方法的有效性和资源需求，为在现实网络安全场景中部署 CNN 提供有价值的洞见。

## V. 结论（CONCLUSION）

在本研究中，我们开发了一种为资源受限物联网设备量身定制的轻量级 CNN-BiLSTM 模型，解决了复杂机器学习模型在 IDS 中应用方面的关键缺口。传统模型虽然有效，但由于计算需求，这类设备通常不适合使用它们。我们的模型不仅考虑了模型复杂度，还实现了较高准确率：在 UNSW-NB15 数据集上，二分类和多分类的准确率分别达到 97.28% 和 96.91%。与近期的混合 CNN-LSTM 架构相比，尽管某些模型在 NSL-KDD 数据集上实现了最高 99% 的准确率，我们的模型在 UNSW-NB15 数据集上仍展现出更优性能。展望未来，我们计划通过探索用于超参数调优的贝叶斯优化（Bayesian Optimization）来改进方法，以提升更简单模型的性能，从而推动物联网环境 IDS 研究的发展。
